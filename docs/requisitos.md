# Requisitos do Sistema

## RF01 — Cadastro de produtos
O sistema deverá permitir cadastrar produtos informando nome, categoria, preço e quantidade inicial.

## RF02 — Consulta de estoque
O sistema deverá permitir consultar os produtos cadastrados e suas quantidades disponíveis.

## RF03 — Registro de vendas
O sistema deverá permitir registrar vendas e calcular o valor total.

## RF04 — Atualização de estoque
Após uma venda, o sistema deverá reduzir automaticamente a quantidade disponível do produto.

## RNF01 — Segurança
O sistema deverá validar os dados recebidos e proteger as informações armazenadas.

## RNF02 — Usabilidade
A interface deverá apresentar opções simples, claras e adequadas ao uso por computador.
