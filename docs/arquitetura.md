## Arquitetura do sistema
O MVP será desenvolvido utilizando uma arquitetura monolítica organizada em camadas

## Interface

Responsável pela apresentação das telas e interface com o usuário. Será desenvolvida utilizando HTML, CSS e templates Flask.

## Lógica de Negócio

Responsável pelo processamento das regras do sistema, incluindo validação de produtos, registro de vendas e atualização do estoque.

## Persistência

Responsável pelo armazenamento das informações utilizando banco de dados SQlite.

## Tecnologias previstas
Python

Flask

SQLite

HTML5

CSS3
