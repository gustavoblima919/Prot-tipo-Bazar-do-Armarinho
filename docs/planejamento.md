## Planejamento de desenvolvimento.

## Etapas previstas

Organização inicial do repositório.

Definição dos requisitos.

Planejamento da arquitetura.

Desenvolvimento da interface.

Implementação das funcionalidades.

Integração com o banco de dados.

Testes do MVP.

Documentação e validação.

## Versionamento

O projeto utilizará o GitHub para registrar a evolução do desenvolvimento.

As mensagens dos commits seguirão um padrão semântico, utilizando prefixos como:

feat: funcionalidades.

fix: correções.

docs: documentação.

test: testes.

## Situação atual

O projeto encontra-se em fase inicial, com documentação e planejamento das funcionalidades principais.
